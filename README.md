# AI Agent Bootcamp LMS

Платформа обучения: программа и записи занятий, домашние задания, прогресс, материалы и оценка проектов с разделением по потокам.

**Для продолжения работы другой LLM начните с [текущего состояния проекта](docs/current-status.md).** На 15.09.2026 новое голосование демо-дня готово и проверено локально, но ещё не опубликовано. Незакоммиченные изменения и QA находятся в этом рабочем каталоге.

Рабочая LMS: https://ai-bootcamp-lms.vercel.app. Стек: Next.js 14.2, TypeScript, Tailwind CSS, Supabase, Vercel. Источник программы и транскриптов — отдельный проект `~/Documents/Cursor/AI Agent Bootcamp`.
